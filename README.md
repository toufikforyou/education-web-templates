# Education Web Templates

School and education website projects by [MH TOUFIK](https://github.com/toufikforyou), collected in one place.
Each project lives on its own `archive/*` branch with its full commit history, exactly as it was in its own repository.

| Branch | What it is | Built with |
|---|---|---|
| [`archive/school-website-design`](../../tree/archive/school-website-design) | A school website template: home, admission, notices, contact and invoice pages | HTML · CSS · JS |
| [`archive/school-dashboard-design`](../../tree/archive/school-dashboard-design) | A school admin dashboard: login, students, teachers, records and rules | HTML · CSS · JS |
| [`archive/infancy-academy-school-website`](../../tree/archive/infancy-academy-school-website) | Infancy Academy School's website and admin panel: online admission, results and school management | PHP · MySQL · Bootstrap |
| [`archive/smart-education-website`](../../tree/archive/smart-education-website) | SmartEDU, a responsive education template: courses, blog, about and contact | HTML5 · CSS · JS |

## Get one

Clone a single project:

```bash
git clone --branch archive/school-website-design --single-branch \
  https://github.com/toufikforyou/education-web-templates.git school-website-design
```

Swap in any branch name from the table. The three HTML templates open straight in a browser from `index.html`;
the Infancy Academy site needs PHP and MySQL, and its README explains the setup.

## History

Each branch was its own repository until November 2026:
`school-website-design`, `school-dashboard-design`, `infancy-academy-school-website` and `smart-education-website`.
The three HTML templates were also served at `*.toufikhasan.com` through GitHub Pages; their `CNAME` files are
still on their branches.
